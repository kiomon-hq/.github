# Support

## Where to get help

| You want to… | Go to |
|---|---|
| Ask how to use an SDK | Open a **discussion** or a question issue in the relevant repository |
| Report a bug | Open an issue in the relevant repository using the bug template |
| Request a feature | Open an issue in the relevant repository using the feature template |
| Report a security vulnerability | Follow the [security policy](SECURITY.md) — never a public issue |
| Read the docs | [kiomon.com/docs](https://kiomon.com/docs) |
| Report a problem with your Kiomon account or the hosted service | [kiomon.com](https://kiomon.com) support |

This organisation hosts the **open-source SDKs** for Kiomon. Issues filed here are answered by the
SDK maintainers on a best-effort basis — there is no support SLA for the open-source repositories.
Support for the hosted product runs through [kiomon.com](https://kiomon.com).

## Before you open an issue

- Search the existing issues, including closed ones — the answer may already be there.
- Reproduce on the latest version, and check the docs for the feature.
- Include the package and version, your language runtime version, and the smallest snippet that
  shows the problem. For an SDK error, the `code`, `status` and `request_id` on the raised error
  are usually enough for us to find the matching request.
